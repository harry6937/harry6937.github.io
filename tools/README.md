# M2 工具中心

手机和电脑自适应的网页工具导航，入口部署在现有 GitHub Pages 仓库的 `tools/` 子目录，保留主站汇率计算器和 `/imei/`。

初始收录 harry6937 的全部 22 个仓库，拆分为 26 个入口。网页直接打开；没有可用静态网页的项目打开仓库，并标明源码、素材、空仓库或未完成。导航接入不代表对各业务工具执行了功能验收。

## 日常使用

- 右上角 ＋：添加名称、网址、分类、图标和说明。
- 卡片 ⋯：编辑工具；星标：收藏。
- 管理：上移、下移、隐藏、移入回收站。
- 设置与备份：新建或改名分类、导出或导入 JSON、打开回收站恢复。
- 手机默认在当前页面打开工具，电脑默认打开新标签页，可在设置切换。
- 最近使用记录和打开方式属于当前设备；工具清单、分类、顺序、收藏、隐藏和回收站进入云端同步。

## 云端同步

通过所有者专用的 Google Apps Script 网页服务读写新建的 Google 表格。浏览器先尝试自动连接；浏览器登录限制导致失败时，点击“连接 Google 云端”，登录后保持连接窗口打开。新设备需要同一个所有者 Google 账号。

保存会显示状态；“本机保存”或“同步未完成”不代表已经上传。连接状态下会自动保存，前台每 45 秒检查云端版本，也可立即同步。离线修改保存在本机，重连时同步；手机和电脑同时修改会提示选择版本，不静默覆盖。冲突的两份清单另存本机 `m2-hub:conflict-backup`，可先导出本机版本。

Google 表格保存追加式完整版本快照。不要手动修改“版本记录”表。删除入口是可恢复操作，不删除网页、仓库或其业务数据。当前版本仅所有者能够读写云端，不是多人权限系统。

Apps Script 初始化代码会创建一张专用表，不操作既有业务表格。OAuth 需要表格读写和登录邮箱权限；Google 的表格授权范围覆盖账号表格，但代码仅使用专用表 ID。部署必须设置“执行身份：我”“谁可以访问：仅限我自己”。

## 源码与验证

静态页面无 npm/CDN 依赖。`python3 -m http.server 8892 --bind 127.0.0.1 --directory m2-tools` 可从父目录预览。`core.js` 负责数据校验、过滤；`cloud.js` 负责 Google 连接；`app.js` 负责交互与同步状态；`seed.js` 仅用于首次访问，后续发布不会重置用户删除的入口。

运行 `node tests/run.mjs` 验证 URL 校验、导入、仓库覆盖、删除保留、云端版本冲突、重复保存和权限隔离。`python3 build_backend.py` 将桥接页面与后端打包为 `apps-script/Deploy.gs`，用于 Apps Script 编辑器。首次运行 `setupToolCenter`，完成授权，然后发布仅所有者可访问的网络应用，将部署地址写入 `config.js`。

发布静态资源：index.html、style.css、icon.svg、seed.js、core.js、config.js、cloud.js、app.js。源码和说明可一并保存。不要发布测试截图或业务数据。
